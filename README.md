# Prototype Streaming Controller
## Program
The Prototype Streaming Controller takes a sample amount of anime from four different streaming services and allows the user to chose a streaming service, chose an anime available on such streaming service, and its episodes, seasons, and/or movies. In this prototype, it is assumed that the user has access to all sites and shows on the four streaming services used.

Created in CodeHS's Under Program Type "Python 3 Server"
